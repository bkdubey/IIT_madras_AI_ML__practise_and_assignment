Objective: Analyse housing data to identify key factors influencing sale prices through exploratory analysis, feature engineering, and predictive modeling.

What this is about: You’ll work with a real-world dataset containing detailed information on property and neighborhood attributes. The project simulates an end-to-end data science workflow—data preparation, insight generation, and model building—similar to tasks carried out in industries like real estate and urban planning.

Your Project Tasks:

Task 1: Data Cleaning and Preprocessing

1.1 Handling Missing Values: Identify and handle missing values appropriately. If there is a missing value, it indicates that the facility is not available. For example, if the "Garage" field is missing, it means the house has no garage. This applies only to categorical columns. For numerical columns of the corresponding field, missing values should be replaced with 0.
1.2 Converting Categorical Variables: Encode categorical variables using suitable methods (e.g., one-hot encoding).
1.3 Normalising Numerical Features: Normalise numerical features to ensure they are on a comparable scale.
1.4 Outlier Detection: Identify and handle outliers in the dataset.

Task 2: Feature Engineering

2.1 Creating Interaction Features: Create meaningful interaction features that may help improve model performance.
2.2 Feature Binning: Bin continuous variables into discrete categories for better interpretability.

Task 3: Exploratory Data Analysis (EDA)

3.1 Analysis and Interpretation: Analyse the dataset to answer specific questions:

What is the distribution of sale prices?
How do different features relate to sale price?
Identify trends and patterns in the data.
3.2 Visualizations: Create plots and charts to represent your findings clearly.

Task 4: Model Building and Evaluation

Build models using XGBoost, LightGBM, and CatBoost to predict sale prices.
Evaluate model performance using metrics such as RMSE, MAE, and R².






Learning outcomes addressed:

Implement advanced ensemble methods using Python libraries 
Evaluate the performance and interpret advanced ensemble models using appropriate metrics

What you’ll learn: Strengthen your ability to clean data, engineer impactful features, visualise trends, and apply machine learning algorithms to make accurate predictions.
