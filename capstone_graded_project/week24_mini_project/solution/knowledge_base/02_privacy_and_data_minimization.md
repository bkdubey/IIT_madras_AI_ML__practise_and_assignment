# Privacy and Data Minimization

Privacy is a core requirement for trustworthy AI. Systems should limit the collection, storage, and use of personal information to what is necessary for the stated purpose. Data minimization reduces the risk of unnecessary exposure and improves user trust.

Before collecting data, teams should identify the minimum viable dataset required for the model objective. If a use case can be supported without sensitive or high-risk variables, those fields should be excluded. This includes avoiding unnecessary personal identifiers and limiting retention periods.

Privacy safeguards also include access control, logging, encryption, anonymization, and consent workflows. AI systems used in consumer products should be transparent about what data is used and how it is protected. In regulated contexts, the governance team should confirm that the deployment aligns with legal and ethical obligations.

Source: Responsible AI Handbook, privacy governance notes.
