# Week 7 Mini Project Submission

This folder contains the final deliverable for the employee attrition project.

## Included files
- `week7_employee_attrition_analysis.ipynb` — final submission notebook
- `report.pdf` — executive summary / project report
- `requirements.txt` — Python package requirements
- `model.pkl` — trained SVM model pipeline saved with joblib
- `Week 7_MiniProject 1.pdf` — supporting project document (original submission PDF)

## How to run
1. Open `week7_employee_attrition_analysis.ipynb` in Jupyter.
2. Run the notebook cells in order.
3. The notebook uses the same dataset and includes model comparison, evaluation, and final output.

## Notes
- `model.pkl` can be loaded with `joblib.load('model.pkl')`.
- This folder is the actual submission package and is structured for final delivery.
