# Detail Implementation — Employee Attrition Analysis

This folder contains the detailed version of the week 7 employee attrition project.

## Files included
- `WA_Fn-UseC_-HR-Employee-Attrition.csv` — dataset used for analysis
- `employee_attrition_analysis.ipynb` — detailed notebook with EDA, model comparison, and evaluation
- `report.pdf` — executive summary / project report
- `requirements.txt` — Python package requirements
- `model.pkl` — final trained model pipeline saved with joblib

## Purpose

- The notebook here compares multiple classifiers and saves the final trained model pipeline.
- This is intended for your personal workflow and not the final submission package.

## How to use
1. Open `employee_attrition_analysis.ipynb` in Jupyter.
2. Run cells top to bottom.
3. The notebook includes model training, evaluation, and feature importance steps.
